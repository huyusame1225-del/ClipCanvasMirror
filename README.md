# Clip Canvas Mirror

Windows用の、イラスト制作向けリアルタイム確認ビューワーです。

## ダウンロード

一般利用者はGitHubの **Releases** ページから最新版の
`ClipCanvasMirror-v*-win-x64.zip` をダウンロードし、展開後に
`ClipCanvasMirror.exe` を起動してください。.NETの追加インストールは不要です。

Windows SmartScreenに警告される場合があります。これは現在の配布版に
コード署名がないためです。信頼できる公開元から取得したファイルであることを
確認してから実行してください。

CLIP STUDIO PAINTなど、画面上の任意範囲をリアルタイム取得し、次の2つの表示を並べるWindows用補助ビューワーです。

- 左右反転
- 知覚輝度、彩度0、階調化、ぼかしなどの確認プレビュー

対象アプリのファイルやレイヤーは操作せず、画面に表示されているピクセルだけを取得します。

## 必要環境

- Windows 10 / 11（64ビット）
- ビルドする場合: [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- 実行のみ: 自己完結型で発行した場合、.NETの別途インストールは不要

## ビルド

PowerShellまたはコマンドプロンプトで、このREADMEがあるフォルダーに移動して実行します。

```powershell
dotnet build -c Release
```

ビルド結果:

```text
bin\Release\net8.0-windows\win-x64\ClipCanvasMirror.exe
```

## 単体EXEとして発行

```powershell
dotnet publish -c Release
```

発行結果:

```text
bin\Release\net8.0-windows\win-x64\publish\ClipCanvasMirror.exe
```

プロジェクトには `win-x64`、自己完結型、単一ファイル発行の設定が含まれています。ファイルサイズを抑えたい場合は、次のようにフレームワーク依存で発行できます（実行先に.NET 8 Desktop Runtimeが必要です）。

```powershell
dotnet publish -c Release --self-contained false -p:PublishSingleFile=true
```

## 使い方

1. CLIP STUDIO PAINTで確認したいキャンバスを表示します。
2. `ClipCanvasMirror.exe` を起動します。
3. 「範囲を選択」を押します。
4. 画面が暗くなったら、キャンバス部分をマウスでドラッグして囲みます。
5. ビューワーに「左右反転」と「明暗確認」が同時表示されます。

範囲選択中は `Esc` でキャンセルできます。

上部の操作:

- **範囲を選択**: 取得範囲を選び直す
- **一時停止 / 再開**: 画面取得を停止・再開
- **表示**: 横並び / 縦並び
- **更新**: 0.5 / 1 / 2 / 5 / 10 / 15 / 30 fps（各項目に負荷の目安を表示）

FPSは1秒間に画面を更新する回数です。数値が大きいほど表示は滑らかになりますが、PCへの負荷も高くなります。
- **常に手前**: ビューワーを他のウィンドウより前に表示
- **表示内容**: 左右反転 / 明暗確認を個別に表示・非表示
- **順番を入れ替え**: 横並びの左右、または縦並びの上下を交換
- **明暗確認方法**: 次の6種類から明暗・色の確認方法を選択
- **設定をしまう / 設定を開く**: 操作欄を折りたたみ、プレビュー領域を広く使用

プレビュー画像の操作:

- **マウスホイール**: カーソル位置を中心に25%～800%で拡大・縮小
- **左ドラッグ**: 拡大した画像を移動（左右反転と明暗確認は個別に操作可能）
- **ダブルクリック**: 拡大率と位置をリセット

確認方法:

- **知覚輝度（基本）**: 人間が感じる明るさに近い比率で変換。主役と背景の分離や明暗設計の基本確認向け
- **彩度0（HSL）**: RGBの最大値と最小値から明度を作る彩度0表示。一般的な「彩度を下げる」結果との比較向け
- **3階調**: 黒・中間・白の3段階。大きな明暗の塊とシルエットの確認向け
- **5階調**: 5段階の明暗。3階調より細かな明暗設計の確認向け
- **ぼかし＋知覚輝度**: 細部を弱め、視線誘導や主役の読みやすさを確認
- **カラー（通常）**: 取得した色をそのまま表示。グレー表示との比較向け

選択範囲、表示方向、表示内容、確認方法、FPS、常に手前、設定欄の開閉、ウィンドウ位置とサイズは終了時または変更時に自動保存されます。設定ファイルは次の場所です。

```text
%LOCALAPPDATA%\ClipCanvasMirror\settings.json
```

## 注意事項

- 取得するのは「画面に見えている内容」です。キャンバスの上に別ウィンドウが重なると、そのウィンドウも映ります。
- 「常に手前」のビューワーが選択範囲に重ならないよう配置してください。
- CLIP STUDIO PAINTを管理者として起動している場合でも通常は取得できますが、問題があれば両方を同じ権限で起動してください。
- HDR表示、色管理、ディスプレイごとのカラープロファイルにより、CLIP STUDIO PAINT内の表示と色が完全一致しない場合があります。
- 高解像度の広い範囲を30 fpsで取得すると負荷が上がります。その場合は10 fps以下に下げてください。負荷を最小限にしたい場合は0.5～2 fpsが適しています。

## プロジェクト構成

```text
ClipCanvasMirror.csproj        ビルド・単体EXE発行設定
App.xaml / App.xaml.cs         アプリ起動定義
MainWindow.xaml(.cs)           プレビュー画面とリアルタイム取得
RegionSelectorWindow.xaml(.cs) ドラッグ範囲選択
AppSettings.cs                 設定の保存・復元
app.manifest                   DPI対応設定
```
